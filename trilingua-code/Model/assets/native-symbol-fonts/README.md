# Native PDF Unicode fallback

These derived fonts combine Noto Sans, monochrome Noto Emoji and Noto Sans
Symbols2 to preserve warning/checkmark symbols together with translated Latin
text. Runtime code verifies the hashes in manifest.json. Existing signed OCR
font assets and their manifest are unchanged.
